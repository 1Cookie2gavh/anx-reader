========================================
 AnxReader（1Cookie2gavh fork · 数据库 v101）
 使用说明 / 首次运行必读
========================================

【一、运行】
  直接双击 anx_reader.exe 即可，无需安装。
  本包已内置 VC++ 运行库，一般系统可直接运行。

【二、如果启动时提示缺少 WebView2 运行时】
  提示内容类似：
    “未能找到已安装的 WebView2 运行时或非稳定版的 Microsoft Edge 安装。”

  原因：AnxReader 使用 Microsoft Edge WebView2 渲染书籍，部分系统未预装。
  解决：双击本目录下的 MicrosoftEdgeWebview2Setup.exe 安装（需联网，约 1.8MB），
        安装完成后重新打开 anx_reader.exe 即可。
  离线环境：可从微软官网下载「Evergreen 独立安装包」（约 200MB）离线安装：
        https://developer.microsoft.com/microsoft-edge/webview2/

【三、数据存放位置】
  书籍、笔记、进度、书评等数据保存在当前用户目录下：
    C:\Users\<用户名>\AppData\Roaming\com.anxcye\anx_reader\
  换电脑时可通过设置里的 WebDAV 同步把数据带到新设备；
  也可以直接复制上述文件夹整体迁移。

【四、关于数据库版本（重要）】
  本版本数据库为 v101，与官方版本（v7 等）以及其他 fork 版本的数据文件互不兼容。
  所有设备请统一使用本 fork 的构建，否则 WebDAV 同步会提示“版本不匹配”并拒绝同步
  （这是保护机制，不会损坏数据）。

【五、功能说明】
  · 多刷阅读统计：读完一本书后可开启二刷、三刷，每一轮独立统计阅读时长与进度
  · 书籍备注 / 书评：书籍详情页可写下每本书的书评，支持 Markdown 语法
  · 其余功能（WebDAV 同步、AI 对话、划线笔记、阅读统计等）与上游一致

【六、未构建平台】
  iOS / macOS 未构建（需要 Mac + Xcode）。
  Android 版请下载对应的 APK 文件。
